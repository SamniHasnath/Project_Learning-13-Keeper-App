# 📝 Keeper App

A modern and responsive note-taking application built with React, inspired by Google Keep. Keeper App allows users to create, manage, and delete notes effortlessly through a clean and intuitive user interface. The application also includes Dark Mode support, smooth animations, and a fully responsive design for an enhanced user experience across all devices.

## 🚀 Features

* ✨ Create notes with a title and content
* 🗑️ Delete notes instantly with a single click
* 🌙 Toggle between Light Mode and Dark Mode
* 🎨 Modern and user-friendly interface
* 📱 Fully responsive design for mobile, tablet, and desktop
* ⚡ Smooth animations and interactive hover effects
* 🧩 Component-based architecture using React

## 🛠️ Tech Stack

* **React.js (Vite)** – Frontend framework
* **JavaScript (ES6+)** – Application logic
* **CSS3** – Styling, animations, and responsive design
* **HTML5** – Markup structure

## ⚙️ Installation & Setup

Follow these steps to run the project locally:

```bash
# Clone the repository
git clone https://github.com/your-username/keeper-app.git

# Navigate to the project directory
cd keeper-app

# Install dependencies
npm install

# Start the development server
npm run dev
```

Open your browser and visit:

```text
http://localhost:5173
```

## 🧩 Core Components

### 🔹 Header

* Displays the application title
* Contains the Dark Mode toggle button

### 🔹 CreateArea

* Input fields for note title and content
* Add Note functionality

### 🔹 Note

* Displays individual notes
* Delete Note functionality

### 🔹 Footer

* Displays application footer and copyright information

## 🌙 Dark Mode Support

The application includes a built-in Dark Mode feature:

* Light Mode → Clean and minimal appearance
* Dark Mode → Modern dark-themed interface

Users can switch between themes instantly using the toggle button in the header.
