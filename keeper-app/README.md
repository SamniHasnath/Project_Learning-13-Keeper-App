
📝 Keeper App (React)
Keeper App is a modern note-taking web application built using React. It allows users to create, view, and delete notes with a clean UI inspired by Google Keep. The app also includes advanced features like dark mode, animations, and a responsive layout.

🚀 Features
✨ Add notes with title and content
🗑 Delete notes instantly
🌙 Toggle between Light and Dark mode
🎨 Clean and modern UI design
📱 Fully responsive (mobile & desktop)
⚡ Smooth animations and hover effects

🛠️ Tech Stack

React.js (Vite) – Frontend framework
JavaScript (ES6+)
CSS3 (Flexbox + Animations)
HTML5
